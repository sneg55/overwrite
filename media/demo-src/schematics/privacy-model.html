Who can see what

The per-depositor book is invisible to everyone except the operator and that one depositor. This is the Daml signatory and observer model, not a client-side filter: the web app server-renders every page with the acting party's own read rights, so an empty view is real ledger visibility.

The observer column is empty by construction: that party is a stakeholder of nothing, so its ledger view is genuinely blank. The claim that carries real weight is the depositor one, that alice cannot see bob. On an EVM option vault every column here would be full, because depositors, vault size, strikes and roll timing are public to everyone.
